# 0005. 開発ツールを比較せずに選ぶ

- ステータス：Accepted
- 日付：2026-09-30
- 関連 Issue：なし

## コンテキスト

開発環境・整形・Gitフック・Markdown の lint に使うツールを決める必要があった。

## 検討した選択肢

ほかの選択肢とは比べていない。

## 決定

次のツールを、作者が使いたかったという理由で採用する。

- 開発ツールの管理: Nix devShell（flake-parts）
- 整形・lint の集約: treefmt（treefmt-nix）
- Gitフック: prek
- Markdown の lint・整形: rumdl

## 結果

- これらのツールを使い続ける特別な理由はない
- 置き換えるときは、比べた結果を新しい ADR に書き、この ADR のステータスを変える
